# 🧵 Urban Threads — Fashion Brand Website

A modern, responsive **fashion e‑commerce front‑end** built with **React** and **CSS**, inspired by premium clothing brand layouts.  
This project demonstrates a clean, stylish design with product listings, promotional banners, trust badges, and a professional footer.

---

## ✨ Features
- **Navigation Bar**: Sticky black nav bar with brand logo, menu links, and cart icon.
- **Hero Banner**: Full‑width background image with overlay text and call‑to‑action buttons (“Shop Men” / “Shop Women”).
- **Product Grid**: Displays items with images, prices, and “Add to Cart” buttons.
- **Promo Banner**: Highlights seasonal sales (e.g., “Mid‑Season Sale | Up to 40% OFF”).
- **Shop by Category**: Visual sections for Men’s Clothing, Women’s Clothing, Accessories, and Footwear.
- **Footer**:
  - Top footer: trust badges (Free Shipping, Secure Payment, Returns, Support) + newsletter signup.
  - Bottom footer: social media icons + payment method logos (Visa, MasterCard, PayPal).
